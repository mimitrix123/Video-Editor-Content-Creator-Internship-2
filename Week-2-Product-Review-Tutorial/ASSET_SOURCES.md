# Week 2 — Asset Sources

No third-party footage, music, product logos, or commercial assets are embedded in the demo script.

For the final video, document every external asset here using:

| Asset | Source URL | License / permission | Usage |
|---|---|---|---|
| Product footage | Add source | Add license | Main video |
| Background music | Add source | Add license | Music bed |
| Product/logo | Add source | Add permission | Call-outs / end screen |

Use only footage, music, graphics, and logos that you have permission to use.
