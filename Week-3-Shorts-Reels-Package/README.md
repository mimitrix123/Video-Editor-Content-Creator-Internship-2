# Week 3 — YouTube Shorts / Reels Package

## Deliverable
A three-video vertical short-form package designed for YouTube Shorts / Instagram Reels.

| Video | Topic | Duration | Format |
|---|---|---:|---|
| 01 | 3 Productivity Tips | 45s | 1080×1920, 9:16 |
| 02 | Smartphone Camera Hacks | 50s | 1080×1920, 9:16 |
| 03 | Quick Desk Setup Transformation | 40s | 1080×1920, 9:16 |

## Required editing elements
- Captions/subtitles with high-contrast safe-area placement
- Music bed with beat-aware edit points
- Punch-in / punch-out zoom effects
- Speed ramps around action moments
- Hook in the first 1–3 seconds
- Matching visual language across all three videos
- One custom thumbnail design per video
- Vertical 9:16 export, 1080×1920
