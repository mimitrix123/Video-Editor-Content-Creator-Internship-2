## SEO checklist
- Put the primary topic naturally in the title.
- Make the first description lines useful without requiring expansion.
- Use chapters for the long-form video.
- Add relevant playlist placement.
- Use only accurate tags/keywords; avoid unrelated keyword stuffing.
- Add a pinned comment with a useful takeaway and a link to the related video when available.
- Write alt-style internal notes for thumbnail concept/testing, but do not rely on metadata to replace strong content.
