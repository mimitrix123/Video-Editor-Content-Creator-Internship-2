# YouTube Channel Setup Blueprint

**Channel name:** Creator Lab India  
**Handle:** Choose an available handle during account setup.  
**Category:** Education / How-to & Style  
**Audience:** beginner creators, students, freelancers, and small businesses.

## About copy
Creator Lab India shares practical, beginner-friendly tips for shooting, editing, and publishing better videos with accessible tools. New tutorials cover smartphone filming, editing workflows, short-form content, and creator productivity.

## Visual identity
- Profile image: simple monogram/logo
- Banner: `Shoot • Edit • Publish`
- Consistent typography across thumbnails
- Intro sting: 2–3 seconds
- Outro: 8–10 seconds with subscribe prompt and next-video area

## Channel setup checklist
- Create/confirm Google/YouTube account
- Choose channel name and available handle
- Upload profile image and banner
- Add About description and contact/business links if appropriate
- Configure default upload settings
- Add channel keywords relevant to the actual content
- Create playlists: `Phone Video`, `Editing Workflows`, `Shorts`
- Add featured video/sections after first uploads
