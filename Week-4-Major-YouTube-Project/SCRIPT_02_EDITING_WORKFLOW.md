# Video 02 — A Simple Workflow to Edit Videos Faster

**Target duration:** ~5 minutes

## 0:00–0:20 — Hook
Editing gets slow when every decision happens randomly. Instead, use the same sequence every time: organize, build the story, clean the audio, add visuals, polish the color, then export. Here's that workflow from start to finish.

## 0:20–1:00 — Step 1: Organize
Create folders for video, audio, graphics, music, exports, and project files. Rename important clips with useful labels. Import everything before making creative decisions so you know what material is available.

## 1:00–1:55 — Step 2: Build the rough cut
Start with the strongest take. Remove mistakes, pauses, and repeated ideas. Don't spend time on transitions yet. The goal is a clear story with good pacing. Once the rough cut works without effects, you're ready for the polish pass.

## 1:55–2:45 — Step 3: Clean audio
Balance dialogue first. Remove distracting noise where appropriate, use gentle compression, and add consistent loudness between clips. Then bring music underneath the voice rather than competing with it. Add short sound effects only where they improve a transition or action.

## 2:45–3:35 — Step 4: Add B-roll, captions, and graphics
Cover jump cuts with relevant B-roll. Add captions for important spoken points and use call-outs for numbers, steps, or key phrases. Keep text readable and consistent. Graphics should support the story, not distract from it.

## 3:35–4:25 — Step 5: Color and pacing
Correct exposure and white balance before applying a creative look. Match clips from different cameras. Then watch the entire edit and remove moments that feel unnecessarily slow. Use zooms, speed changes, and transitions selectively.

## 4:25–5:00 — Step 6: Export and review
Export a high-quality master and the platform version. Watch the exported file from beginning to end on a phone and computer. Check spelling, audio, cuts, graphics, and the first 30 seconds. Fix anything distracting before publishing. Subscribe for more editing workflows.
