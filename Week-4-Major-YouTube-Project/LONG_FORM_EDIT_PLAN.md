# 5-Minute Long-Form Edit Plan

**Format:** 1920×1080, 16:9, 30 fps, H.264/AAC

| Time | Section | Visual treatment |
|---|---|---|
| 0:00–0:20 | Hook | Fast cuts, title animation, 2–3 B-roll inserts |
| 0:20–1:05 | Lens + framing | Talking head + close-up lens/frame examples |
| 1:05–2:00 | Lighting | Window-light demo, before/after exposure |
| 2:00–2:50 | Stabilization | Tripod/handheld comparison + punch-ins |
| 2:50–3:45 | Composition + audio | Framing examples + microphone B-roll |
| 3:45–4:35 | Editing-minded shooting | Wide/medium/detail montage |
| 4:35–5:00 | Recap + CTA | 5-point checklist + subscribe/outro |

## Editing recipe
1. Build dialogue rough cut.
2. Add B-roll over jump cuts.
3. Add captions to key lines rather than every word if the chosen style calls for selective captions.
4. Add subtle 105–115% punch-ins to emphasize key points.
5. Use speed changes only for demonstrations or montage moments.
6. Add licensed music underneath dialogue at a restrained level.
7. Apply exposure/white-balance correction and match shots.
8. Add intro at the beginning and branded outro at the end.

## Audio target
Prioritize clear dialogue, then music and SFX. Leave sufficient headroom and verify the final mix after export.

## B-roll checklist
- Phone lens cleaning
- Window-light setup
- Tripod setup
- Handheld stabilization
- Framing examples
- Microphone/recording close-up
- Wide/medium/detail shot sequence
