# Publishing Checklist

## Before upload
- [ ] Final master watched end-to-end
- [ ] Dialogue, music, and SFX checked
- [ ] Captions/spelling checked
- [ ] Thumbnail exported
- [ ] Rights/license records complete
- [ ] Title and description finalized
- [ ] Chapters/timestamps prepared
- [ ] Playlist selected
- [ ] End screen and cards prepared where applicable

## Upload
- [ ] Upload video in YouTube Studio
- [ ] Add title and description
- [ ] Upload custom thumbnail
- [ ] Add playlist
- [ ] Add audience setting accurately
- [ ] Add subtitles/captions
- [ ] Add end screen
- [ ] Add relevant cards
- [ ] Check visibility and scheduling

## Publish one video
Publish **Long-form Video 01** after the above checks and record the actual published URL in `PUBLISH_RESULT.md`.

## After publishing
- [ ] Verify public playback
- [ ] Check thumbnail/title on mobile
- [ ] Record publish date/time
- [ ] Capture initial analytics after a meaningful observation period
- [ ] Use audience/retention data to inform future edits rather than changing multiple variables at once.
