# Intro / Outro Package

## Intro — 3 seconds
**0:00–0:01:** quick visual hit / logo reveal  
**0:01–0:02:** channel name: `Creator Lab India`  
**0:02–0:03:** tagline: `Shoot • Edit • Publish`

Keep the intro short so it does not delay the video's hook.

## Outro — 8–10 seconds
**Primary:** `Thanks for watching!`  
**CTA:** `Subscribe for practical creator tutorials`  
**Secondary:** `Watch the next video →`  
**Layout:** subscribe prompt plus space for a next-video/end-screen element.

## Shorts ending
Use a 2–3 second compact CTA: `Save this • Follow for more`.
